# 📚 Student Toolkit - Features Guide

## Dashboard 📊

See your study progress at a glance:
- **Focus Sessions**: Number of completed 25-minute focus sessions
- **Tasks Completed**: Count of finished tasks
- **Study Sessions**: Total planned study sessions
- **Average Grade**: Your calculated average from all tracked grades

## Exam Countdown 📅

Keep your next exam visible:
- Enter exam name and date
- Automatic countdown timer
- Shows "Exam day is here!" when the date arrives

## Study Planner 🗓️

Plan your study schedule:
- Add subject name
- Set date and time
- Duration in minutes
- View all planned sessions
- Delete sessions you no longer need

## Task Manager ✅

Manage homework and study tasks:
- Add task description
- Set priority (Low, Medium, High)
- Mark tasks as complete/incomplete
- Delete tasks
- Visual strikethrough for completed tasks

## Focus Timer ⏱️

Pomodoro-style timer:
- 25-minute default timer
- Start, Pause, Reset buttons
- Automatic alert when session completes
- Increments "Focus Sessions" count when finished
- Shows in MM:SS format

## Study Notes 📝

Write and save notes:
- Large text area for study notes
- Auto-save to browser storage
- Clear button to delete all notes
- Useful for quick note-taking during study sessions

## Calculator 🧮

Quick calculations:
- Add (+)
- Subtract (−)
- Multiply (×)
- Divide (÷)
- Instant results

## Grade Tracker 🎓

Track your academic performance:
- Add subject name
- Enter grade (0-100%)
- View all grades
- Delete individual grades
- Dashboard shows average grade automatically updated

## Unit Converter 📏

Convert common units:
- Meters ↔ Kilometers
- Meters ↔ Centimeters
- Kilograms ↔ Grams
- Instant conversion
- Support for decimals

## Flashcards 🎴

Create study flashcards:
- Add question
- Add answer
- Click card to reveal answer
- Delete cards
- Great for memorization and review

## Dark Mode 🌙

Modern dark theme:
- Click 🌙 in header to toggle
- Preference saved automatically
- Easy on the eyes for night studying
- All features work in dark mode

## Local Storage 💾

All data persists:
- No account needed
- Data stored in your browser
- Survives page reloads
- Private and secure
- Clear browser cache to reset

---

**Tip**: Use the Study Planner + Task Manager + Focus Timer together for the best productivity workflow!
